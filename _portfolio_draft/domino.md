# Domino, the go-to platform for creating data and A.I workflows!

**Introduction:**
The data and AI landscape is exploding with publicly available tools, but most still require programming skills to use or to integrate with different systems. Take ChatGPT, for example, it's an incredible tool that's widely known and easy to use, however, if you need to integrate ChatGPT (or any other advanced tool), with your business data sources, you'd probably have to ask developers to handle the task. This is a common problem, and every problem comes with a solution, and the solution is called **Domino**!

**About Domino:**
Domino is an open-source, no-code platform for creating, collaborating, managing and deploying advanced data and AI workflows. With Domino, anyone can build customized data workflows using an intuitive drag-and-drop visual interface, as simple as putting dominoes pieces together. Domino promotes reusability and reproducibility, enabling developers to easily create and reuse their code, distributing it to a whole community of users (public or private), as "Domino pieces", this means that anyone can instantly utilize these codes directly in the UI without coding!

**These are the key features that make Domino stand out:**

✅ User-friendly NO-CODE drag-and-drop GUI for creation of complex data and AI workflows.
![Domino GUI](/assets/portfolio/domino_drag_and_drop_page.png)

✅ Versioned, shareable and reproducible workflows.
![Domino Workflows](/assets/portfolio/domino_workflows_page.png)

✅ Modular Pieces that are reusable, immutable, isolated, and ready-to-run, enhancing collaboration and efficiency.
✅ Decentralized framework for Pieces development and distribution, enabling users to share their work with the community.

✅ Clean and intuitive GUI for monitoring workflows results, including real time logs and rich reports with styled text, images, iterative graphics and more.

✅ Collaborative workspaces.
![Domino Workspaces](/assets/portfolio/domino_workspace_page.png)


**And more, Domino is**:
✅ Scalable, Kubernetes native platform.
✅ Powered by Apache Airflow for top-tier workflows orchestration.
✅ Open source license: we want to foster community contribution.



To ensure all this features and their robustness across the entire platform, Domino relies on a strong technology stack:

- **React** for the frontend, providing an intuitive user interface.
- **FastAPI** for the Domino API, facilitating communication between frontend and other services.
- **Postgres** for the database, ensuring reliable storage of workflow and user data.
- **Apache Airflow** for workflow orchestration, enabling scheduling, monitoring, and execution of complex workflows.
- **Kubernetes** for scalable deployment, ensuring efficient resource utilization and reliability in production environments.
- **GitOps** for versioning workflows and distributing pieces, ensuring consistency and reproducibility in workflow management and deployment.


**Conclusion**
Domino is a transformative solution, being more than just an API integration and a simple workflow automation tool like others. It provides users the ability to create any data and AI workflows, whether you are running simple tasks or resource-intensive operations. From small businesses who want to use cutting-edge technologies with ease to big organizations with sensitive data that want to enable all teams to run their custom Artificial Intelligence models or data pipelines, Domino is here for everyone.
